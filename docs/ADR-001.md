# ADR-001: Architecture Decision Record

## Context
Founding Engineer building Flyby MVP from scratch.

## Decisions

1. **Monorepo with npm workspaces** — Keeps API and PWA in one repo, easy shared types later.
2. **Express + Prisma + PostgreSQL** — Prisma gives strong type safety and migrations; PostgreSQL is the standard choice.
3. **React 19 + Vite + Tailwind CSS** — Fast DX, small bundle, Tailwind gives fast UI iteration.
4. **PWA via vite-plugin-pwa** — Handles service worker, manifest, and install prompt out of the box.
5. **Vitest for testing** — Unified across API and web, fast, native TS support.
6. **Redis for caching/SSE pub/sub** — Will be wired into `WaitTime` reporting and live updates.
